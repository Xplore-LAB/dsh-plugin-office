## ⚡ 概览

**Postbird 是 DeepSeek Harness 的本地优先 AI 邮箱与办公助手。** 它能从收件箱中找出今天最重要的事情，识别截止日期和等待回复事项，读懂邮件线程并准备回复，再把信息继续变成 Word、PPT、表格和可移交归档。

> **你只需要：** 用自然语言描述任务，按需提供邮箱授权码或本地文件。
>
> **Postbird 会交付：** 今日简报、行动清单、上下文回复，以及 `.eml`、`.csv`、`.xlsx`、`.docx`、`.pptx` 等真实文件。

QQ、163、126、Gmail、Outlook 等常见邮箱均可接入。收件默认只读，发件必须先预览再确认，索引和生成文件保留在你的电脑上。

## ✨ 一分钟看懂 Postbird

打开 [Postbird Live Demo](https://xplore-lab.github.io/postbird/demo/)，依次体验三个核心场景：

| 核心能力 | 你只需这样说 | Postbird 给你的结果 |
| --- | --- | --- |
| ☀️ 每日简报 | “帮我开始今天的工作” | 从邮件中选出最重要的 5 件事，折叠低价值信息 |
| ◎ 行动雷达 | “找出截止事项、等待回复和需要催办的邮件” | 任务、负责人、截止时间、状态和原邮件依据 |
| ↩️ 上下文回复 | “结合这条邮件线程，帮我准备回复” | 线程上下文、行动要求和三种可编辑回复 |

每个判断都附有依据。任何邮件发送都要经过预览和明确确认。

### 我们的愿景

让每个人现有的邮箱和本地文件，直接获得一层可信、可控、可交付的 AI 办公能力。

1. **面向个人：** 一句话整理收件箱、跟踪行动、准备回复、生成文档，把时间留给判断与创造。
2. **面向团队：** 把群发、材料收集、归档、交接和批量制表沉淀为可复核、可重复执行的工作流。

## 🚀 三步开始

### 1. 安装

```bash
git clone https://github.com/Xplore-LAB/postbird.git
cd postbird
npm run setup
```

安装器会自动发现 DeepSeek Harness 配置、安装运行依赖并注册插件。存在多个配置时指定一个：

```bash
npm run setup -- --profile web
```

### 2. 检查

```bash
npm run doctor
```

自检会分别报告核心功能、收件能力和发件能力。文档、PPT、表格、草稿与本地分析无需邮箱凭据即可使用。

### 3. 开始对话

重启 DeepSeek Harness，然后直接描述目标：

```text
读取这份销售 CSV，按地区汇总，生成 Excel 和一份管理层汇报 PPT。
```

需要处理邮箱时，再按[中文使用指南](docs/GUIDE.zh-CN.md#邮箱接入可选)配置授权码。QQ、163、126、Gmail、Outlook 均提供预设，无需自行查找服务器地址。

## 🛡️ 安全可控

| 设计 | 默认行为 |
| --- | --- |
| 本地优先 | 邮件索引、附件和生成文件保留在本机 |
| 收件只读 | IMAP 操作默认 `readOnly` |
| 发送确认 | 先生成预览，只有明确确认才会发送 |
| 真实交付 | 邮件与办公文档写入可检查的标准文件 |
| 凭据隔离 | 授权码从环境变量读取，不写入代码仓库 |

更多说明见[安全策略](SECURITY.md)。
