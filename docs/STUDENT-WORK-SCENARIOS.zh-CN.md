# Postbird 学生工作与学生社团场景地图

> 配套文档：[校园邮箱场景手册](MAIL-SCENARIOS.zh-CN.md) · [中文使用指南](GUIDE.zh-CN.md) · [安全策略](../SECURITY.md)

学生工作中的邮箱任务通常贯穿报名、审核、筹备、执行、报销、总结和交接。Postbird 将邮件、报名表、活动材料、附件和截止日期放进同一条可复核工作流，让学生干部和指导老师直接看到当前状态、缺失项、下一步与来源依据。

## 一、涉及哪些人

| 人员 | 主要工作 | 最常处理的邮件与材料 |
| --- | --- | --- |
| 活动参与者与报名者 | 报名、补件、取消、确认到场 | 报名表、证明材料、作品、缴费凭证、确认邮件 |
| 班委、团支书与项目干事 | 收通知、统计名单、催交材料 | 班级回执、评优材料、活动报名、签到记录 |
| 招新与会员负责人 | 招募、资格核对、面试和录取沟通 | 招新表、个人陈述、可参加时间、面试评价 |
| 活动负责人 | 策划、审批、场地、人员和进度协调 | 策划案、审批表、安全预案、分工表、物资表 |
| 志愿服务负责人 | 招募、排班、签到和时长认定 | 志愿者名单、培训记录、签到签退、服务证明 |
| 宣传负责人 | 海报、推文、摄影和新闻稿 | 宣传文案、设计稿、审批记录、照片与总结稿 |
| 财务负责人 | 预算、采购、票据、决算和报销 | 预算表、发票、订单截图、支付记录、签领表 |
| 社团负责人和秘书处 | 年审、会议、换届和完整归档 | 章程、通讯录、会议纪要、年度总结、交接目录 |
| 指导教师、辅导员和团委老师 | 审核活动、把控风险、确认经费和结果 | 活动方案、审批表、安全材料、预算决算、总结 |

## 二、十类高频工作场景

### 1. 招新报名与面试安排

常见问题：报名从邮件、表格和附件同时进入，院系、年级、意向部门和可参加时间格式不统一，同一人可能重复提交或更新版本。

```text
整理本次社团招新报名，找出重复报名和缺失信息，生成面试安排。
```

Postbird 可以：

1. 按活动主题发现报名邮件，无需预先准备完整名单。
2. 提取姓名、院系、年级、联系方式、意向部门和可参加时间。
3. 合并同一邮箱的多次提交并标记最新版本，保留全部邮件依据。
4. 检查报名表、个人陈述等必交材料。
5. 输出候选人台账、缺失信息清单和面试时间表。
6. 生成补件、面试邀请和结果通知草稿，发送前完整预览。

人工边界：录取、淘汰和部门分配需要负责人决定。Postbird 只整理材料与准备沟通。

### 2. 活动报名、名额与候补管理

常见问题：报名量突然增加，重复报名、资格条件、取消和候补递补需要反复核对，活动前还要逐人确认是否到场。

```text
汇总迎新活动报名，按报名时间保留 80 人，整理候补和未确认名单。
```

Postbird 可以：

1. 汇总报名、取消、改期和确认邮件。
2. 标记重复记录、名单外来件、缺失字段和资格待核验人员。
3. 按负责人确认的规则生成正式名单与候补名单。
4. 识别尚未确认到场的人员。
5. 准备确认、候补和递补通知，并展示收件人预览。
6. 导出 Excel 名单和现场签到表。

### 3. 比赛、征集与作品材料收集

常见问题：报名表、承诺书、作品、PPT、视频、缴费截图和证明文件缺一不可，文件格式、匿名要求、团队人数和命名规则又容易出错。

```text
检查创新比赛报名邮件，告诉我每支队伍缺什么，哪些文件命名或版本不合规。
```

Postbird 可以：

1. 按队伍或负责人聚合多封提交邮件。
2. 检查必交材料、附件格式、文件名、大小和版本线索。
3. 从报名表中核对团队成员、指导教师和联系方式。
4. 将实名版、匿名版、签字版和可编辑版分别归类。
5. 标记重复参赛、人数限制和待人工确认项。
6. 生成逐队缺件清单、补件草稿、汇总表和附件索引。

### 4. 活动策划与审批材料包

常见问题：一场活动可能同时需要策划案、活动审批表、安全预案、预算、场地申请、宣传品审批、外来人员信息和保险证明。

```text
检查读书会活动材料，按审批顺序整理，还缺什么就列出来。
```

Postbird 可以：

1. 从通知和模板中提取全部审批项与提前量。
2. 检查活动主题、时间、地点、规模、人员分工、预算和安全措施。
3. 将场地、宣传、保卫、后勤和指导老师审批分别列出。
4. 识别缺签字、缺盖章、缺附件和版本冲突。
5. 生成审批材料目录、待办清单和 Word 情况说明。
6. 保留每项结论对应的邮件、PDF 页或 Word 段落。

### 5. 场地、宣传、设备与外联协调

常见问题：活动日期和场地可能冲突，海报和宣传物料需要审批，设备、用电、外来人员或商业赞助还会增加流程。

```text
把这次活动的场地、海报、设备和赞助沟通整理成一张推进表。
```

Postbird 可以：

1. 汇总多个部门的回复和历史承诺。
2. 提取场地时间、布场时间、设备清单、联系人和审批状态。
3. 发现时间冲突、尚未回复和即将逾期事项。
4. 生成按负责人排列的行动雷达。
5. 为场地确认、宣传送审和供应商沟通准备上下文回复。
6. 输出活动推进表和联系记录。

### 6. 志愿者招募、排班与服务时长

常见问题：志愿者报名后还要培训、排班、签到签退、异常说明和时长认定，临时替班容易造成记录不一致。

```text
整理志愿者报名和签到，核对排班、缺勤、替班和服务时长。
```

Postbird 可以：

1. 汇总报名表、培训通知、排班表和签到记录。
2. 检查时间冲突、岗位缺口和未确认人员。
3. 对照签到签退计算待认定时长，并标记异常记录。
4. 生成补充说明和证明材料清单。
5. 输出志愿者台账、岗位排班和服务证明草稿。

人工边界：服务时长认定和异常补录必须由有权限的负责人审核。

### 7. 现场签到、物资发放与证书名单

常见问题：报名名单、实际到场、物资签领和证书姓名经常存在差异，活动结束后还要追补记录。

```text
对照报名表和签到表，生成实际到场、缺席、物资签领和证书名单。
```

Postbird 可以：

1. 对照报名、确认和签到数据。
2. 标记同名人员、学号冲突、缺席和临时到场人员。
3. 关联物资或奖品签领记录。
4. 生成待复核证书姓名与邮件地址。
5. 输出 Excel 对账表、证书名单和遗漏提醒草稿。

### 8. 预算、票据与报销

常见问题：预算必须先批，活动后需要决算、发票、订单截图、支付记录、签领表、活动证明和情况说明，金额或日期不一致会导致退回。

```text
检查这次活动报销材料，核对预算、发票、支付记录和活动证明。
```

Postbird 可以：

1. 对照预算与实际支出，计算项目差额和总额差异。
2. 检查发票抬头、日期、金额、附件和对应采购项目。
3. 标记缺少订单截图、支付记录、合同、签领表或说明的条目。
4. 将票据按报销要求生成索引和目录。
5. 输出决算表、缺件清单、Word 说明和完整归档包。

人工边界：财务合规判断、票据真伪与最终报销审批由学校财务人员确认。

### 9. 新闻稿、活动总结与成果报送

常见问题：活动结束后，照片、新闻稿、参与数据、获奖情况、反馈和经费信息分散在不同同学手里。

```text
把活动邮件、签到、照片说明和反馈整理成总结、推文初稿和汇报 PPT。
```

Postbird 可以：

1. 汇总策划目标、实际参与、签到数据和执行记录。
2. 提取可验证的活动数字与重要节点。
3. 整理照片文件名、拍摄人和使用说明。
4. 生成 Word 活动总结、推文初稿和 PPT 概览。
5. 建立来源索引，避免宣传数据与原始记录不一致。

### 10. 年审、评优、换届与工作交接

常见问题：章程、成员名单、会议纪要、活动档案、财务记录、获奖证明和账号交接分散，临近年审或换届时才集中补材料。

```text
把本学年社团材料按年审目录归档，列出缺失项，生成换届交接清单。
```

Postbird 可以：

1. 搜索全学年相关邮件并批量归集附件。
2. 按基础档案、活动档案、财务档案、宣传成果和荣誉材料分类。
3. 检查计划、审批、通知、签到、总结、照片和决算是否齐全。
4. 生成年度大事记、活动总表和缺失材料清单。
5. 输出可移交目录、CSV 索引、Word 交接说明和汇报 PPT。

## 三、最适合首屏展示的学生组织 Demo

```text
帮我整理校园文化节的报名和活动材料，告诉我现在最需要处理什么。
```

演示数据：

1. 126 封报名与补件邮件。
2. 96 名报名者。
3. 5 项必交材料。
4. 7 份重复提交。
5. 14 人材料不全。
6. 6 人尚未确认到场。
7. 4 项活动审批等待完成。

Postbird 的演示流程：

```text
按主题发现报名者
        ↓
合并同一人的多次提交
        ↓
核对报名表与活动材料
        ↓
生成缺件、名单外来件和待确认队列
        ↓
提取场地、宣传、安全与预算节点
        ↓
准备逐人补件提醒和负责人待办
        ↓
导出活动总台账与归档目录
        ↓
等待负责人复核与发送确认
```

一分钟内展示的结果：

| 看板 | 展示内容 |
| --- | --- |
| 报名状态 | 有效报名、材料不全、重复提交、待确认到场 |
| 活动推进 | 场地、宣传、安全、预算和负责人状态 |
| 优先行动 | 今天要催谁、等谁回复、补哪份材料 |
| 来源依据 | 原邮件、附件名、PDF 页、Word 段落和表格行 |
| 可下载结果 | 报名台账、缺件清单、活动推进表和归档索引 |

## 四、Postbird 能力映射

| 工作需要 | 当前能力 | 组合方式 |
| --- | --- | --- |
| 开放报名，无预先名单 | 已支持 | `office_collection_track` 使用 `participantMode: discover` 按主题发现报名者 |
| 已有名单逐人核对 | 已支持 | `office_collection_track` 使用 roster 模式，输出缺件和名单外来件 |
| 重复提交与补交版本 | 已支持 | 材料台账标记同一邮箱的多封提交并保留时间和证据 |
| 检查附件内容 | 已支持 | `office_attachment_ask` 返回 PDF、Word、PPT 和 Excel 精确出处 |
| 截止时间和负责人 | 已支持 | `office_action_extract` 与 `office_action_radar` 提取并排序行动 |
| 长线程和跨部门回复 | 已支持 | `office_thread_summary` 与 `office_reply_draft` 还原上下文并准备草稿 |
| 个性化补件和确认通知 | 已支持 | `office_mail_preview` 校验收件人、正文和附件后等待明确确认 |
| Excel、Word 与 PPT | 已支持 | `office_sheet`、`office_docgen`、`office_pptx` 生成真实文件 |
| 年审与换届归档 | 已支持 | 归档工具导出原始邮件、附件和 CSV 索引 |
| OA 审批状态自动同步 | 后续扩展 | 需要学校系统提供授权接口和权限范围 |
| 多人共享活动看板 | 后续扩展 | 需要角色权限、冲突处理和协作审计能力 |
| 日历与签到平台同步 | 后续扩展 | 需要用户授权的日历或签到平台连接 |

## 五、易用性原则

1. 用户只需说活动名称和目标，Postbird 再按需询问名单、必交项或截止时间。
2. 开放报名可以从指定主题的邮件自动发现人员，避免先做一份名单才能开始。
3. 同一人的重复提交会保留版本和时间，负责人决定采用哪一版。
4. 缺件提醒按个人实际缺失内容生成，发送前统一预览。
5. 每个状态都保留邮件和附件依据，低置信度内容进入人工复核。
6. 报名结果、录取决定、时长认定、财务审批和敏感信息处理始终由有权限的人确认。
7. 报名表只收集完成活动所需的最小信息，并明确用途、保存时间与负责人。

## 六、公开流程依据

本场景地图参考了高校公开办事指南和材料要求：

1. [西南大学学生社团活动申请](https://jgdw.swu.edu.cn/info/1151/5231.htm)列出了策划案、审批表、预算与结算表，大型或校外活动还需要紧急预案和保险证明。
2. [中国石油大学（北京）学生活动审批流程](https://www.cup.edu.cn/tuanwei/docs/2021-11/0c661a9b173e4e4c9480bcd80ade53d3.pdf)覆盖活动方案、宣传材料、场地和经费审核。
3. [中国传媒大学校园活动场地审批流程](https://zcsp.cuc.edu.cn/home/content?id=57)体现主管单位、团委、后勤、保卫和现场查验等环节。
4. [北京大学医学部学生活动管理办法](https://xgb.bjmu.edu.cn/yycy/gzsw/214434.htm)要求活动策划包含目的、时间、地点、人员、宣传、安全、预算、分工和场地准备。
5. [北京交通大学大学生交通科技大赛通知](https://bjctrans.bjtu.edu.cn/zxdt/tzgg/7ddc81d7fb9d4f93addc1e3482e81f2f.htm)展示了报名表、作品申报书、匿名与实名版本、统一汇总和文件命名要求。
6. [华中师范大学大广赛征集通知](https://jc.ccnu.edu.cn/info/1065/6153.htm)展示了作品、报名表、承诺书、缴费截图、学生证和明细表的组合收集场景。
7. [中国石油大学（北京）学生社团活动经费细则](https://www.cup.edu.cn/tuanwei/202606xg/szyxxt/stjszdb/dcb68c41e725455ca23bb4dfb3960670.htm)覆盖预算申请、发票、订单与支付截图、签领表、总结宣传和决算报销。
8. [华北电力大学学生组织社团档案范围](https://dag.ncepu.edu.cn/dagd/ssda2/xszzstda/949734dd980440fbac3cf491d505077c.htm)覆盖章程、成员、计划总结、会议记录、活动审批、宣传、照片和荣誉材料。
9. [浙江大学青年志愿者工作细则](https://ls.zju.edu.cn/_upload/article/files/64/30/01069d5f45a7b0580b0b17a02715/00efc85f-29c0-4be0-8ebc-6c54fa131d9f.pdf)体现志愿服务签到签退、服务时数和证明材料要求。
10. [中华人民共和国个人信息保护法](https://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)要求个人信息处理目的明确、范围最小，并采取安全保护措施。

不同学校的审批层级、时间要求、报销标准和材料模板存在差异。Postbird 应先读取用户所在学校的最新通知与模板，再生成对应清单，关键审批结论保留人工确认。
